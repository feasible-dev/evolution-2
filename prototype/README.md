# Evolution Wars — playable project

Open `project.godot` here in Godot 4.6.1 .NET. `Main.tscn` launches the broadcast
slice; `EvolutionTwo.csproj` targets .NET 8. The root repository's Godot project
is a separate older sandbox.

From the repository root, run `Lancer-Evolution2.ps1` (`-Test` for smoke checks,
`-Language fr` for French). See [root README](../README.md) for installation paths.

Current runtime: v52 character framing and emotional continuity. Presenters are
12.5% larger; Nico has 128x192 portrait/reaction frames, with his name beside his
body. Gerard's standing sequence returns into an excited seated reaction with
consistent head size and restrained speaking shapes. The LED fascia preserves
end-cap proportions and masks the lower hands. Speech bubbles fit their text.

Current art choices and pending integration are tracked in
[CURRENT_STATE](../docs/CURRENT_STATE.md), not in a cumulative version changelog.
The new island hangar/neon sign and opponent entrances are **not integrated yet**.
Runtime assets remain in `assets/`; selected sources/previews are in
[`art-direction/`](../art-direction/README.md).
